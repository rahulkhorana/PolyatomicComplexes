# Contributing to Polyatomic Complexes

Thanks for your interest in contributing! Here's how you can help:

## 🛠 Reporting Issues

## 🙋 Community & Support

Please use [GitHub Discussions](https://github.com/rahulkhorana/PolyatomicComplexes/discussions) to:
- Report bugs or unexpected behavior
- Request new features
- Suggest improvements

## 💡 Contributing Code

1. Fork the repository
2. Create a new branch (`git checkout -b feature-xyz`)
3. Make your changes
4. Submit a pull request

Please include tests and clear commit messages when possible.

## 💬 Seeking Support

Open an issue for support questions.
